Quickstart

All API endpoints are served over HTTPS from __DOMAIN__ using UTF-8 JSON payloads. Include an API token in the Authorization header:

curl -sS https://__DOMAIN__/v2/projects \
  -H "Authorization: Bearer <api_token>" \
  -H "Accept: application/json"

Successful responses return a deterministic envelope with cursor pagination:

{
  "object": "list",
  "data": [
    { "id": "prj_01j8k2m4", "name": "core-service", "region": "us-east" }
  ],
  "next_cursor": null
}

Authentication

Create environment-scoped tokens from your workspace settings. Tokens follow the Bearer scheme and may be restricted to read-only or deployment scopes.

  • Requests without valid credentials receive HTTP 401 Unauthorized.
  • Requests lacking required scope receive HTTP 403 Forbidden.
  • Rotate tokens periodically using overlapping active keys for zero-downtime rollover.

Webhooks

Event subscriptions deliver signed POST requests to your configured HTTPS listener. Verify the X-Signature-256 header against the raw request body using your endpoint signing secret.

EventDescriptionRetry Policy
deployment.createdEmitted when a new release artifact is registeredExponential, 24h max
deployment.readyEmitted after health checks pass in target regionsExponential, 24h max
token.rotatedAudit event for scheduled credential replacementExponential, 24h max
