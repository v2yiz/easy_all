Product

One governed model, from raw events to board metrics

Northlake sits on top of the warehouse you already own and adds the parts spreadsheets never had: definitions, tests, owners and review.

Model once, read everywhere

Sources are declared in version control, not clicked together in a browser. Every model carries an owner, a description and SQL tests that run on each change.

  • Automatic lineage from source table to published metric
  • Freshness and volume monitors with alert routing
  • Environment separation for staging and production models
models/activation_daily.sql
select
  date_trunc('day', e.occurred_at) as day,
  e.workspace_id,
  min(e.occurred_at) filter (where e.name = 'first_report') as activated_at
from events.raw_events e
where e.occurred_at >= current_date - interval '400 days'
group by 1, 2

Engineering details

For the people who will actually run it.

Deployment

A single container in your VPC, or a private tenant in ours. Outbound HTTPS only, no inbound firewall changes.

Access control

SAML SSO, SCIM provisioning and role-based access down to model and column level.

Auditability

Every query, publish and permission change is written to an append-only audit log you can export.

Backups

Model definitions live in git. Metadata snapshots run hourly with 35-day retention.
