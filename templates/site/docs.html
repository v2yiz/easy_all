Documentation

Everything below is versioned in git alongside your models. The current CLI release is 2.7.1.

Quickstart

Install the CLI, authenticate with a workspace token, and connect the warehouse with a read-only role.

shell
curl -fsSL https://__EASY_ALL_SITE_DOMAIN__/install.sh | sh
northlake auth login --workspace example
northlake warehouse connect --type snowflake --role NORTHLAKE_RO
northlake model sync --path ./models

The connect step prints the exact grants the read-only role needs. No data leaves the warehouse.

Models

Models are plain SQL with a small header block describing owner, refresh cadence and tests.

models/mrr_movement.sql
-- owner: finance
-- refresh: hourly
-- tests:
--   - not_null: invoice_id
--   - unique: invoice_id
select
  invoice_id,
  customer_id,
  date_trunc('month', period_start) as month,
  mrr_usd,
  movement_type
from billing.invoices

Run northlake model test locally to execute the same tests the review bot will run.

API reference

All endpoints are HTTPS only and authenticated with a workspace token in the Authorization header.

MethodPathPurpose
GET/v1/modelsList published models and their owners
GET/v1/models/{name}/rowsQuery model rows with filters and pagination
POST/v1/models/{name}/refreshTrigger an on-demand refresh
GET/v1/auditExport audit events for a time range
example request
curl -sS https://__EASY_ALL_SITE_DOMAIN__/v1/models/activation_daily/rows \
  -H "Authorization: Bearer $NORTHLAKE_TOKEN" \
  -G --data-urlencode "since=2026-10-01"
