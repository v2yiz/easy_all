# Globalping 注册与 Token 获取指南

## 1. 注册账号

1. 打开 [Globalping Dashboard](https://dash.globalping.io/)。
2. 选择 **Sign in with GitHub**。
3. 在 GitHub 页面确认登录和授权。
4. 返回 Globalping Dashboard，确认已经显示你的 GitHub 用户名。

## 2. 创建 Access Token

1. 登录后打开 [Dashboard Tokens](https://dash.globalping.io/tokens)。
2. 选择 **Generate a new token**。
3. 输入能说明用途的名称，例如 `easy_all_aws_cdn`。
4. 确认创建。
5. 立即复制并妥善保存 Token；关闭页面后无法再次查看完整内容。

## 3. 安全保管

- 不要把 Token 提交到 Git。
- 不要把 Token 写入 README、截图或公开日志。
- 不要在聊天、Issue 或其他公开渠道发送 Token。
- 怀疑泄露时，应立即在 Globalping Dashboard 撤销并重新创建。

官方参考：

- [Globalping Dashboard](https://dash.globalping.io/)
- [Globalping Token 页面](https://dash.globalping.io/tokens)
